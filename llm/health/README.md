# 健康ログ（iPhoneヘルスケア → 毎朝、前日分を確定してMacに記録）

記憶には入れず、Macのファイルに記録して必要なときだけ呼び出す。
Claude・ChatGPT・Gemini・Copilot・ローカルLLMはすべてこのファイルを元にする。

## 置き場所
~/MyTool/llm/health/health_log.csv（これ1つだけ）

列: date,steps,weight,body_fat_pct,fat_mass,bp_sys,bp_dia,pulse
- date は記録対象の日（前日）。同じ日付が再送されたら最後の内容で上書き
- 歩数＝前日の合計、体重・体脂肪率＝前日の最初の測定（朝。朝晩測った日も朝の値）、体脂肪量＝体重×体脂肪率（Mac側で計算）、血圧・脈拍＝前日の最初の測定（朝）
- 機器: 体重・体組成＝オムロン（OMRON connect）、血圧・脈拍＝A&D
- 体脂肪量: ショートカットから届く5番目の値（除脂肪体重）は使わず、health.py が体重×体脂肪率で計算して記録

## Mac側の準備（1回だけ）
1. システム設定 → 一般 → 共有 →「リモートログイン」をオン（自分のユーザーのみ許可）
2. iPhoneのショートカットで作ったSSH鍵（公開鍵）を ~/.ssh/authorized_keys に追記
3. 朝もiPhoneからつながるよう、システム設定 → バッテリー（またはエネルギー）→ オプション →
   「ネットワークアクセスによるスリープ解除」をオン（電源接続時）

## iPhoneショートカット「健康ログ」
1. 現在の日付 →「日付を調整」で「日の始まりを取得」→ 変数「今日0時」
2. 「日付を調整」今日0時 から 1日 を減算 → 変数「昨日0時」
3. 「日付をフォーマット」昨日0時 を カスタム yyyy-MM-dd → 変数「日付」
4. 「ヘルスケアのサンプルを検索」歩数／開始日が 昨日0時〜今日0時 の範囲内／グループ化: 日
   →「ヘルスケアサンプルの詳細を取得」値 → 変数「歩数」
5. 同様に検索（グループ化なし、開始日で並べ替え 古い順、制限 1＝朝の測定）→ 値:
   体重→「体重」、体脂肪率→「体脂肪」、除脂肪体重→「除脂肪」
6. 同様に検索（開始日で並べ替え 古い順、制限 1）→ 値:
   最高血圧→「最高」、最低血圧→「最低」、心拍数→「脈拍」
7. 「SSH経由でスクリプトを実行」
   ホスト: Macのローカルホスト名（システム設定 → 一般 → 共有 の下に表示される ○○.local）
   ポート 22／ユーザ dsk_nagaoka／認証: SSH鍵
   スクリプト:
     /usr/bin/python3 ~/MyTool/llm/health/health.py --add "日付" "歩数" "体重" "体脂肪" "除脂肪" "最高" "最低" "脈拍"
   （値が空・「10,432」・「61.6 kg」・「0.183」でもMac側で数値に直して記録する）
8. 「通知を表示」[SSHの出力]（「記録しました: …」が出れば成功。失敗時はエラーが出る）

## オートメーション
個人用オートメーション →「アプリ」→ OMRON connect と A&D Connect を選び「閉じられたとき」→「すぐに実行」→ ショートカット「健康ログ」
（朝の測定・同期後にアプリを閉じた時点で実行＝ロック解除中なのでヘルスケアを読める。何度動いても前日分の上書きになるだけ）
Macが同じWi-Fiにいない・眠っていて届かない日は失敗通知が出るので、Macにつながる所で
ショートカット「健康ログ」を手で1回実行すればよい（前日分を記録）。

## 呼び出し方
- ローカルLLM: /health [日数]（既定14日）。体重・血圧・歩数などの話題では自動で読み込む（その会話だけ、記憶には残さない）
- ローカル3体: ./multi/ask3.sh -H "質問"（-H 30 で30日）
- ターミナル: python3 ~/MyTool/llm/health/health.py [日数]
- ChatGPT・Gemini・Copilot: Claudeに「健康ログを付けて三者に聞いて」→ ClaudeがこのファイルをMacから読み、質問に添えて送る
- Claude: 「健康ログを見て」でOK（Macにつながっているとき）
- Claude: 「ヘルスケア」とだけ送ると、chart_widget.py で体重・体脂肪率・体脂肪量のグラフ（直近1年）をチャットに表示

## 過去分の取り込み（ヘルスケアの書き出しから）
1. iPhoneのヘルスケアApp → 右上のプロフィール写真 →「すべてのヘルスケアデータを書き出す」→ zip をAirDropでMacへ
2. python3 ~/MyTool/llm/health/import_export.py ~/Downloads/書き出したデータ.zip --dry-run（件数の確認）
3. 問題なければ --dry-run を外して実行（書き込み前に health_log.bak-日時.csv を作る）
- 既にある日付は残す（--overwrite で置き換え）、今日の分は取り込まない、--since yyyy-MM-dd で開始日を指定できる
- まとめ方は毎朝のショートカットと同じ。歩数だけは複数の記録元（iPhone・Watchなど）の二重計上を避けて、合計が最大の記録元を採用
